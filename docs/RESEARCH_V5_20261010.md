# 固定路侧双层记忆的完整训练复核与持续 Query 下一版

日期：2026-10-10。此记录承接 `RESEARCH_V3_20261010.md` 与 `RESEARCH_V4_20261010.md`。本轮保留原始 CenterPoint、D2、GRAE checkpoint 和历史输出，所有新产物隔离在 `outputs/research/dual_bev_v5/`、`outputs/research/query_feedback_v1/` 与 `outputs/research/attention_query_v2/`。

## 迁移边界与实现

- [Neural Map Prior](https://github.com/Tsinghua-MARS-Lab/neural_map_prior) 的官方说明明确采用当前特征读历史先验、GRU 递归维护空间记忆；本项目移植该读写分离思想，未声称逐行复现其源码。该仓库的深层源码目录在当前网络环境无法稳定取得。
- [ST-Occ 的不确定性模块](https://github.com/matthew-leng/ST-Occ/blob/main/mmdet3d/models/stocc/modules/uncertainty.py) 组合历史/当前特征、观测次数、距离和 aleatoric 信息；本项目用当前/历史差异与 LiDAR hit 作为可学习路由输入，不把 hit 当成真实遮挡概率。
- [RoadOcc](https://arxiv.org/html/2609.27677) 区分固定地址 Persist、运动地址 Transport、当前观测 Refresh，并明确把历史读取位置与来源选择分开。论文当时写明代码待发布；本实现依据公开方法描述自主适配二维 BEV 检测，而非复制其稀疏体素网络。
- [StreamPETR 的历史 proposal 缓存](https://github.com/exiawsh/StreamPETR/blob/main/projects/mmdet3d_plugin/models/dense_heads/streampetr_head.py) 与 [Sparse4D 的 InstanceBank](https://github.com/HorizonRobotics/Sparse4D/blob/main/projects/mmdet3d_plugin/models/instance_bank.py) 为下一版 Query 的出生、时间传播、更新和失效提供参考。

`src/inframot3d/perception/dual_bev_memory.py` 是独立的 1,310,630 参数模块：512 通道 BEV 压到半分辨率 64 通道，静态/动态各用 ConvGRU，动态分支预测后向采样位移，三路 softmax 决定历史静态、迁移动态和当前观测的读取，最后回到检测头前的原通道。`openpcdet_temporal_adapter.py` 按 `backbone_2d` 后、检测头前的统一特征接口接入；按序列 ID 重置，动态状态超过 0.35 s 清空，静态状态在同序列内允许最长 30 s。关闭模块返回原 BEV。

训练用原 fold A CenterPoint 初始化；另一折 `inner_train` 18 条序列、3071 帧，`inner_holdout` 5 条、728 帧。冻结 3D 提取器，联合优化 BEV 骨干、CenterHead 与记忆模块；4 帧截断 BPTT，8 epoch，检测损失加动态区域及目标位移辅助监督。推理不使用 GT、未来帧或预计算 D0 轨迹。第 6 epoch 验证总损失 5.857 最低；第 8 epoch 回升到 6.137，后续评估统一使用 `pA/best.pth`。

相对原 D0，完整网络找回其固定阈值漏检 486 个 GT 帧位中的 118 个，但失去 200 个原本检出的帧位，净少 82 个。30–60 m 召回从 D0 的 0.89964 升至 0.91508；≥60 m 却从 0.95282 降至 0.93106。稀疏回波组仅 57 个 GT，完整网络检出 37 个，与 D2 相同，不作稳健增益结论。对同权重关闭记忆的检测器，记忆只找回 520 个漏检中的 23 个，净少 48 个。以上 GT 只用于离线分层分析。

## 下一版：目标 Query 参与当前检测

`src/inframot3d/perception/persistent_query_feedback.py` 已实现在线 Query Bank（约 136k 参数）：从当前检测结果出生；保存 Query ID、外观 embedding、三维框、水平速度、类别、置信度、位置不确定性及连续漏检数；下一帧先按速度传播，在预测位置读取当前 BEV，经 GRU 更新，再把局部 Query 特征写入 **CenterHead 前** 的 BEV。检测后用类别、距离与外观匹配更新，短暂漏检保留、超时失效、跨序列重置。反馈的可靠性由历史分数、位置不确定性、漏检数、时间差及当前局部特征学习。无历史时严格返回原 BEV，避免旧网络“当前帧残差”捷径。推理的出生、匹配与更新都只依赖本系统当前/过去预测。

`scripts/research_v5/train_query_feedback.py` 从原始 fold A CenterPoint 权重出发，在连续序列中联合训练 BEV 骨干、检测头与 Query 反馈；对预测目标中心和存在性提供 GT 训练监督，GT 不参与在线 Query 更新。原 3D 提取器仍冻结；BEV BatchNorm 统计固定，卷积参数继续训练。`infer_query_feedback.py` 保存逐帧检测和 Query 状态，支持关闭反馈和逐帧清空的关键对照。接口测试覆盖因果出生/传播/重置、身份保持和跨帧梯度；3 帧因果推理接入已通过。

一次必要的集成检查发现 OpenPCDet `CenterHead.get_loss()` 会把热力图原位 sigmoid。若先计算 loss 再调用 `generate_predicted_boxes()`，热力图会被二次 sigmoid，导致约 590 个虚假出生候选填满 64 个 Query。现已改为**先从原始 logits 解码，再计算 loss**；修复后两帧检查的平均出生候选约 14、Query 数约 14。此前错误输出仅在 `/tmp/query_feedback_smoke_*`，未作为正式实验。正式 8 epoch 训练及最终 AP/HOTA 结果见后文。

第 2 epoch 的中途对照曾显示风险（**不是最终模型结论**）：完整 Query 的 AP / 固定阈值召回为 `0.96373 / 0.87960`，同权重关闭反馈为 `0.97488 / 0.94539`；经原 GRAE 的 HOTA / DetA / AssA 分别为 `0.68451 / 0.64834 / 0.72681` 与 `0.71584 / 0.68941 / 0.74846`。训练未因此提前终止。原 D0 的 486 个固定阈值漏检中，464 个已有低分候选、22 个无对应候选。双记忆完整网络找回低分组 117 个、无候选组 1 个，而同权重关闭双记忆也找回完全相同数量；这进一步把低分目标收益归于检测器微调。第 2 epoch Query 反馈仅找回低分组 59 个，关闭反馈可找回 101 个。上述分组只用 GT 做离线归因。

下一版候选结构需避免两个已观察到的捷径：双记忆无历史时的当前帧残差，以及未经确认的 Query 直接改写 512 通道 BEV。拟保留慢速静态 ConvGRU；以已确认 Query 的位置、速度、外观及不确定性构成稀疏动态 Transport，而非再维护几乎零位移的独立密集动态 flow；以当前/历史特征一致性、LiDAR hit、Query 存在置信度和漏检时长进行可靠性路由。仅当历史有效且 Query 可靠时向检测头提供局部、受限的先验，不能让错误出生立即污染周围 BEV。训练须覆盖完整连续序列，联合检测、Query 存在/位移及身份约束；`0066` 的重复 GT ID 不进入身份监督。该结构目前是**待验证设计**，是否实现与参数选择要由第 8 epoch 的反事实检测和跟踪指标决定。

PAAF 的 `Sparse2DenseDebug.py` 在 3D 稀疏骨干内逐层融合相机与 LiDAR；其 BEV 骨干后同样生成 `spatial_features_2d`，可由独立适配器接入，但此轮尚未完成 V2X-Seq 时序多模态数据接线与 PAAF 训练，不能声称跨骨干性能已经验证。`0066` 的重复 GT ID 问题在后续 fold B 身份监督和分析中仍须剔除或单列。

## 注意力版本 v2：完整 8 轮实验

`attentive_query_feedback.py` 在同一 Query Bank 上加入 5×5 局部 BEV token、4 头交叉注意力、位置编码与前馈层：目标状态按速度先传播，再以目标 Query 选择预测位置附近的当前观测，更新 embedding / 位置 / 存在置信度。相较 v1 的单点读取，它允许目标在定位误差和局部遮挡下选择更合适的观测。写回仍在 CenterHead 前，但以可学习的小初始增益开始；在线 `update` 取未写回的当前 BEV，避免自激式外观污染。无历史时返回原特征，跨序列重置。约 `192,388` 参数；v1 Query 为 `136,067`。7 项接口测试通过；4 帧 TBPTT 接线检查 72 训练帧、20 验证帧通过。注意力版本仍是动态目标级原型，尚未与长期静态 ConvGRU 联合训练，也未接入 PAAF。

**已验证：**第 8 轮历史注意力反馈相对同权重关闭反馈，AP@0.25 `+0.00365`、HOTA `+0.00366`、DetA `+0.00438`、AssA `+0.00264`、IDSW `13→5`；固定阈值每帧 FP `0.614→0.477`。但固定阈值 TP `7645→7577`（少 68 个、召回 `-0.00836`），AP@0.5 只增加 `0.00042`，IDF1 略降；绝对 AP/HOTA 未超过 D0、D2 或 Query v1。GRAE 官方协议计 8267 个 GT 帧位，第 8 轮关/开的 TP 为 `7718/7530`、FP 为 `480/364`，同样显示检测变保守；不要将 DetA 上升误读为召回上升。

**已验证：**注意力不是恒定均匀权重。25 个局部位置均匀分布的熵上限为 `ln 25≈3.219`，第 2/4/6/8 轮留出集的平均熵为 `3.085 / 2.961 / 3.013 / 3.026`，第 8 轮最大位置权重均值 `0.113`（均匀为 `0.04`）；历史写回全图 RMS 约为当前 BEV 的 `7.4%`。然而权重集中没有转化为难目标召回。原 D0 在此五条序列的 486 个固定阈值漏检中，464 个已有低分候选、22 个无候选；第 8 轮注意力开启/关闭分别找回低分组 `119/128` 个、无候选组 `0/1` 个。GT 只用于此离线分组，不参与在线推理。AP@0.25 的正收益主要来自排序与误检抑制，不是已证实的弱目标恢复或更准定位。`0084` 单序列 AP 由关的 `0.8780` 升至开的 `0.9226`，但仅 63 帧，视为局部现象而非泛化结论。两次推理运行在不同 GPU 且有其他负载，`manifest.json` 的耗时不能作为严格的开销对比。

**下一步待验证的模型设计：**不继续堆叠注意力头或重复旧 StaticGate 调参。下一版应把静态 ConvGRU 作为慢时间尺度、与固定坐标对齐的背景层；动态层以已持续确认的 Query 为主，统一保存身份、位置、速度、特征与不确定性，避免另设几乎零流速的密集动态状态。静态写入需由在线 Query 占据区与当前/历史一致性共同抑制车辆残留；目标 Query 对当前 BEV 和静态背景分别做局部交叉读取，再学习可靠性驱动的 Persist / Transport / Refresh。尤其要保护当前帧高可靠观测，只在局部观测弱或不一致时允许历史信息明显改变检测头输入。训练时保留完整序列 TBPTT 与检测器联合优化，并考虑对清晰帧的原检测器输出做一致性约束、对稀疏或短暂缺测帧做时序增强训练；这些是针对本轮“降低 TP、提高精度”现象提出的**设计假设**，不是已经验证的性能提升。PAAF 接入仍需单独适配 AnchorHead/VoxelRCNN 和时序多模态数据，不能把 CenterHead 指标直接迁移过去。
